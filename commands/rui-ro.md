Lập sổ rủi ro cho: $ARGUMENTS

1. Nếu chưa có báo cáo rà soát: dùng skill `ra-soat-hop-dong` (bước 1–5) để xác định rủi ro.
2. Dùng skill `quan-tri-rui-ro`: chuẩn hóa mô tả, chấm mức bằng `danh_gia_rui_ro`, đề xuất biện pháp, người phụ trách, mốc xem lại.
3. Đầu ra: tóm tắt theo mức → sổ rủi ro → ma trận → rủi ro cần người có thẩm quyền quyết định. File xuất ra luôn là file mới.
